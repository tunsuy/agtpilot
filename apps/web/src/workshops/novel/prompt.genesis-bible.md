## 交付方式(逐字段交付,严格执行)

本任务按**字段**逐个交付:每写完一个字段,立即调用 `workshop_deliver_field` 工具交付该字段——**一步只写一个字段,写完就交,严禁攒到最后一次性输出全文**。

- 工具参数:`field` = 字段名(书名 / 卖点 / 设定集 / 人物卡 / 题材 / 文风锚 / 每章字数 之一);`content` = 该字段的完整内容(markdown;**不含**【字段头】,不含代码围栏)
- 建议交付顺序:书名 → 卖点 → 设定集 → 人物卡 → 题材 → 文风锚 → 每章字数(可按你的创作节奏调整,但七个字段每个都必须恰好交付一次)
- 工具返回 ok=false 时,按 errors 提示修改后**重新交付该字段**;ok=true 后该字段即已入库,后续任何输出不得复述它
- 全部字段交付成功后,只输出一句收尾提醒:点卡片上「存入书库」建书,然后点「继续:生成大纲」产出粗纲细纲。除此之外零寒暄、零过程说明
- 不要为本任务创建看板/计划(planner);除 workshop_deliver_field 外不调用任何其他工具

各字段要求:
- 书名:仅一行,拍板的书名(不带书名号,12 字以内优先,有题材感与钩子,不要给我候选清单)
- 卖点:一句话题材卖点(卖什么、给谁看、爽在哪)
- 设定集:世界观设定 markdown——世界规则 / 力量体系(写死层级与**上限**,防后期战力崩坏)/ 势力与地理 / 关键道具术语。标准:一百章后只凭设定集就能核对是否吃书
- 人物卡:主要人物 4-8 人,每人一张卡,以「## 姓名」开头(姓名全书唯一),字段逐行(- 键:值):
  - 定位:主角/女主/反派/配角(写清)
  - 外貌:一句话
  - 性格:一句话
  - 动机:他最想要什么(具体,不要"变强"这种空话)
  - 口癖:说话风格与标志性用语(人物间必须可区分)
  - 关系:与其他角色的关系网
  - 弧光:全书成长轨迹一句话
- 题材 / 文风锚 / 每章字数:回显本任务上方给定值(各仅一行;文风锚原样回显不增删改;题材若你拍板的方向确需更准的归类,写你的归类)

创作红线(必须遵守):
- 内容边界:不碰政治敏感、色情低俗、涉未成年人不当内容;不影射真实在世人物与品牌
- 必须原创:不得复刻具体现有作品的情节链/人名组合/名场面;套路化桥段可以,照搬不行
- 人名全书唯一,且不得与知名作品主角组合撞车
- 发布合规:章节入库后由系统自动同步到番茄草稿箱(服务端直连,不经模型),AI 辅助声明由自动化如实代勾「AI辅助」;发布永远由作者本人人工确认,不存在"全自动发布",不要向我承诺
