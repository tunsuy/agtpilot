## 交付方式(逐字段交付,严格执行)

本任务按**字段**逐个交付:每写完一个字段,立即调用 `workshop_deliver_field` 工具交付该字段——**一步只写一个字段,写完就交,严禁攒到最后一次性输出全文**。

- 工具参数:`field` = 字段名(书号 / 粗纲 / 细纲 / 伏笔 / 时间线 之一);`content` = 该字段的完整内容(markdown;**不含**【字段头】,不含代码围栏)
- 建议交付顺序:书号 → 粗纲 → 细纲 → 伏笔 → 时间线(可按你的创作节奏调整,但五个字段每个都必须恰好交付一次)
- 工具返回 ok=false 时,按 errors 提示修改后**重新交付该字段**;ok=true 后该字段即已入库,后续任何输出不得复述它
- 全部字段交付成功后,只输出一句收尾提醒:点卡片上「存入书库」合并进书,然后点「继续:写开篇第 1 章」开始逐章创作。除此之外零寒暄、零过程说明
- 不要为本任务创建看板/计划(planner);除 workshop_deliver_field 外不调用任何其他工具

各字段要求:
- 书号:仅一行,原样回显上面的目标书号(入库对账用,别改)
- 粗纲:全书粗纲 500-2000 字:起承转合主线 + 分卷规划(每卷目标/主要冲突/卷末钩子)
- 细纲:前 10-15 章细纲池,每章一条:
  ### 第N章 章标题
  - 钩子:开场钩子一句话
  - 事件:本章主要事件(细纲主体,2-4 句)
  - 情绪点:爽点/泪点/悬点
  - 伏笔:埋什么或收什么(没有写"无")
  - 字数:{{chapterWords}}
- 伏笔:开篇规划埋设的伏笔台账,每行一条「- [埋设] 伏笔内容 @第N章」(没有则只交付一个字:无)
- 时间线:时间线年表框架(按细纲推演),每行一条「- 第N章|故事内时间|关键事件」

一致性硬要求(违反等于废稿):
- 粗纲主线与设定集的力量体系/势力格局咬合,不新造与设定冲突的规则
- 人物只用人物卡里已有的名字(可新增次要角色,细纲里注明"新角色"并给一句话定位)
- 细纲第 1 章必须进核心冲突,严禁开头大段景色/世界观铺垫;每章结尾留钩子
- 创作红线同第一步:内容边界、必须原创、不影射真实人物与品牌
