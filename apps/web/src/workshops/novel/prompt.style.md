【文风锚】
150-600 字的文风描述,必须覆盖五点,写成可执行的创作指令(「用短句、动作戏白描」),不写文学评论:
- 叙事节奏与章感:段落长短、场景切换频率、章末钩子习惯
- 句式与用词偏好:长短句配比、修辞密度、允许/回避的词汇类型
- 对白风格:口吻、人物声音如何区分、对白与叙述的配比
- 情绪与爽点处理:直给还是克制、铺垫多长、爆发点怎么写
- 氛围与意象习惯:常用感官通道、环境描写的功能与分量

创作红线(必须遵守):
- 样文合规:只接受作者本人创作或已获授权的文本;若样文疑似他人作品摘录,只提炼通用文风特征,严禁复刻其情节链/人名组合/名场面
- 文风锚只描述「怎么写」,不携带「写什么」:样文里的具体情节、人名、设定一律不进锚
- 提炼必须忠于样文:样文里没有的特征不要硬加(锚会长期注入全书 prompt,编造特征等于污染)

输出完毕后只提醒一句:审阅文风锚,满意后点卡片按钮写回书目(或复制留作开书时的文风锚)。
